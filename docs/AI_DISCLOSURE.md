# AI use disclosure

An AI model (Claude, by Anthropic) wrote much of the code and documentation
that Mollusk OS adds to FunKey OS, including the tools that draw its launcher
themes and logo, under the maintainer's direction.

Changes are built and tested by the maintainer before they are kept, on a
real FunKey S wherever they can be tested there. Prompts, chat transcripts
and session files are development leftovers, not project source, and are
not part of this repository.

Bug reports and contributions are judged on their technical quality,
whether or not AI tools were used to make them.
